# TalaTrace 1.2.0

TalaTrace, formerly **Whisper Transcription**, adds direct microphone recording and a choice of local Whisper and Parakeet engines. The new name reflects the app's broader model support. Audio processing stays on your device.

## Main changes since 1.1.5

- Record an answer, stop and transcribe, then copy it directly into a chat or terminal. Separate recording and file workflows keep controls in stable locations.
- Copy readable timestamps and locally detected gaps in speech alongside the words. These estimates give an LLM pacing context; they do not establish thinking time. TXT, SRT, VTT and JSON exports remain available.
- Use Parakeet TDT 0.6B v3 (Q8_0) or Whisper models, including Large v3 Turbo. The Parakeet runtime is included in the Windows package; model weights are downloaded separately. Parakeet supports transcription, not translation.
- Retain speech after long pauses using lossless audio partitioning for Parakeet.
- Download verified model files, delete installed models to reclaim space, and remember the selected model between sessions. Startup model discovery no longer hashes the whole library.
- View audio duration and processing time for recordings as well as imported files. Sort Models and History tables.
- See a live local frequency display during recording, choose light/dark/system appearance, and use transcription settings in a Candor dialog. Transcript details are available in a collapsed footer.
- Update to Candor 6 constructions, clearer disabled-state guidance, persistent notifications and consistent typography, icons and scrollbars.

## Rename and upgrade

The repository is now [pawn002/talatrace](https://github.com/pawn002/talatrace). Existing repository, issue and release links redirect to the new name, including the links in the original blog post. The README also preserves that post's old Quick Start fragment.

The installer app ID and legacy profile directory names remain stable. The app retains an existing `Whisper Transcription` profile; a new profile uses the internal `whisper-electron-app` directory. Model preferences survive a packaged-app restart. History remains scoped to the current app session.

The Windows 1.1.5 → 1.2.0-rc.1 in-place upgrade passed: all four downloaded models retained their SHA-256 hashes, saved settings survived, Desktop/Start Menu shortcuts were renamed and target the new executable, and one uninstall entry retained the original identity. Installed Tiny and Parakeet transcription passed offline. The previous release remains available for recovery; a downgrade has not been tested. The old repository name must remain unused to preserve redirects.

The final 1.2.0 installer was then installed over RC1 and verified against the same retained profile and models. Tiny and Parakeet transcription pass with HTTP(S) blocked, and the selected model remains Parakeet.

## Validation and limits

- Windows x64 unsigned installer and ZIP. Parakeet's local runtime is included; downloaded weights are stored on this device.
- 130 frontend tests and 42 Electron/release-tooling tests pass.
- Actual packaged executable: Whisper Base and Parakeet recognize the bundled JFK sample with HTTP(S) blocked, report timing/duration metadata, retain a temporary legacy profile and preserve model selection on restart. Clean-profile launch also passes.
- The existing workflow visual review covers 126 states. An existing navigation reflow issue remains at 240px effective width (480px at 200% zoom); this is not a complete accessibility audit.
- NSIS in-place upgrade, shortcut targets and single uninstall-entry retention are verified on the user's existing 1.1.5 installation. The real profile and all weights were backed up first; the existing Parakeet preference remains selected. Fresh NSIS installation, uninstall and rollback have not been exercised. Windows Sandbox is unavailable on the build host. macOS/Linux packages and code signing have not been validated for this release.
