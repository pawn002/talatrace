# Candor widget construction review

Reviewed 24 October 2026 against the published [Candor Storybook](https://main--69c25e2492ad056c24329876.chromatic.com) and the released 6.0.0 story and construction files. Package versions are pinned to 6.0.0; only the tooltip and toast component entry points are imported, with Lit 3.3.2 as a direct peer dependency. Existing Angular behaviour and native controls remain where the table below records an equivalent construction.

## Inventory and decisions

Source paths below are relative to [Candor's released component sources](https://github.com/pawn002/candor/tree/v6.0.0/src/web-components/components). For each row, reviewed the `.stories.ts` file and corresponding `.ts` construction, including the documentation embedded in the story metadata.

| Widget | Story source | App construction and conformance work |
| --- | --- | --- |
| Tooltip | `tooltip/candor-tooltip.stories.ts` | Actual `candor-tooltip` wraps the History icon buttons. Triggers retain independent accessible names; no native title attributes remain. Text is supplementary, AT-hidden, and not attached through aria-describedby. Left placement is chosen for available space; the component does not auto-flip. Verified focus, hover, Escape and pointer entry into the top-layer bubble. |
| Toast | `toast/candor-toast.stories.ts` | Actual `candor-toast` inside a permanently mounted `candor-toast-container`. Removed the three/five-second expiry API and timers. Candor owns neutral surfaces, icons, dismissal and pre-existing polite/assertive regions; Angular removes a toast on dismiss. A timed unit regression now verifies that notifications remain readable. |
| Button | `button/candor-button.stories.ts` | Native buttons preserve click/disabled behaviour. Bold labels, semantic variants and focus; ghost hover/pressed fill follows the current construction. Icon-only History actions use filled 28px glyphs; glyphs beside text are regular. Workflow buttons deliberately use 14px bold at 44px minimum targets to preserve the three fixed action locations at narrow widths, analogous to the documented density knobs. |
| Tabs | `tabs/candor-tabs.stories.ts` | Native ARIA tabs retain Arrow/Home/End, roving tabindex and labelled panels. Restored 16px regular labels, semibold selected labels, primary underline and focus tokens. Source subtabs now share the documented underline construction instead of a separate pill convention. Compact mobile padding prevents page overflow. The fixed two/three-tab lists fit the tested minimum width, so overflow arrows are unnecessary. |
| Accordion hierarchy | `accordion/candor-accordion-item.stories.ts` | Native details/summary retains the reviewed default/subtle hierarchy: 16px bold parents and 16px regular subtle children. The app has no third help-disclosure level needing quiet. Spatial insets adapt at 360px without reducing timestamp size. Mouse and Enter activation preserve the parent. |
| Standalone disclosure | `disclosure/candor-disclosure.stories.ts` | Timing explanation and settings are independent contextual reveals, not an exclusive accordion set. Their native expanded state remains independent. No group-close coordination was introduced. |
| Card/surface | `card/candor-card.stories.ts` | Inner workflow/transcript and Models/History panels use the outlined page-surface construction with semantic borders/radii, rather than an elevated fill without its required shadow. Nested step cards use the default surface. Workflow is already a named section; main panels retain their named tabpanel semantics. The three-step sequence itself is app-specific composition, not a Candor widget. |
| Select | `form/select/candor-select.stories.ts` | Native select remains appropriate for the stable model and 11-language lists. Real labels, 16px values, semantic control borders, minimum target and closed-state caret match the construction. Caret is decorative and follows focus colour; the OS owns the open picker. |
| Checkbox | `form/checkbox/candor-checkbox.stories.ts` | The timing choice configures the subsequent explicit Copy action. Native checkbox stays inside its visible label; its hidden-input/visible-box construction, 20px geometry, token border/fill/check and focus follow Candor. Label is 16px Atkinson with body tracking. There is one independent choice, so no artificial fieldset group is added. |
| Badge | `badge/candor-badge.stories.ts` | Model speed/accuracy labels name their condition in a column context. Small badges are 14px bold Atkinson; medium is 16px regular. Neutral fill uses muted/default text, coloured variants use their matched text/background roles. Header status uses the same small-label font discipline with an additional explicit state icon. |
| Alert | `alert/candor-alert.stories.ts` | Inline recording/copy errors have persistent alert semantics, a bold status glyph, neutral surface and 16px default-colour body text. Model guidance is an info alert with the same construction. Messages required for recovery stay beside the relevant controls. |
| Table | `table/candor-table.stories.ts` | Semantic native tables now have visible captions and named scroll regions only when overflowing. Numeric sizes/durations right-align in mono; dates remain left-aligned mono. Filenames are ordinary text and wrap rather than truncate. Zebra rows and header/body pairings follow the construction. A shared ResizeObserver directive adds/removes the scroll wrapper's keyboard stop as it overflows/fits. |
| Progress | `progress/candor-progress.stories.ts` | Download bars remain indeterminate when no percentage is known and expose a labelled progressbar without a fabricated value. Loading is explicitly named in status text. Decorative workflow spinner is supplementary to the live status heading. Reduced-motion rules stop bar/spinner animation. |

Typography, spacing and icon-role guidance were also reviewed in the design-token stories during the migration. All readable text remains at least 14px; sequential instructions/errors and transcript prose are 16px. Native form controls are intentional, not assertions that importing CSS gives them Candor's component implementation.

Workflow connectors follow the [Icons story](https://main--69c25e2492ad056c24329876.chromatic.com/?path=/docs/design-tokens-icons--docs) and `src/web-components/design-tokens/icons.stories.ts`: Phosphor `ph-bold ph-arrow-right` for informational direction, one weight class, explicit 16px sizing with line-height 1, and decorative aria-hidden. This app-specific sequence centers each arrow in the gap and rotates it downward when the steps stack. Its subtle foreground is measured against the workflow panel behind the gap, rather than the adjacent step card.

The arrow follow-up rebuilt successfully and reran all 44 preview states without page overflow or undersized text. Inspected desktop recording/file workflows, the 360px stacked recording workflow, and light-theme results. All 45 sampled pairings pass klar 3.1.0, including the connectors. Transcription styles are now 7.41 kB, below the existing 8 kB hard limit; the existing bundle/style budget warnings remain.

## Verification and limits

Completed four render/inspect/refine passes plus final fixture verification. Final results: 44 captured states; no measured page-wide horizontal overflow; no readable text below 14px, including open shadow roots; 42 sampled pairings pass klar 3.1.0. `npm test` passes all 98 frontend and 18 Electron tests. The native offline interview smoke test passes recording, transcription, Copy, repeat/discard and file transcription with HTTP(S) blocked and a synthetic microphone. The production build passes at approximately 579 kB raw / 109 kB estimated transfer; transcription styles are approximately 7.23 kB, below the unchanged 8 kB error limit.

The preview uses the real compiled app, including the published Candor modules, with isolated IPC/audio fixtures and blocked HTTP(S). It checks native checkbox/summary/tab behaviour, tooltip focus/hover/Escape/pointer persistence, pre-existing toast announcement regions and explicit dismissal, conditional table focus, minimum text size and responsive layout. Screenshots are inspected across light/dark and narrow layouts, not merely generated. Klar measurements include the actual tooltip/toast shadow text as well as app-authored pairings. The fake file-picker failure is deliberate and prints an expected IPC error during preview.

Use `npm run preview:workflow`, followed by `node tests/electron/candor-contrast.cjs <metrics.json> <absolute-path-to-klar.js>`. The separate offline interview smoke test exercises the native recording/transcription/copy path. Unit tests cover notification retention and existing application behaviour.

Per-component imports add approximately 31 kB raw / 9 kB estimated transfer to the main bundle compared with the tokens-only migration. Build warning categories remain initial bundle size and transcription component stylesheet size; the hard limits are unchanged. This review does not claim full accessibility conformance or a manual screen-reader audit.
