# TalaTrace 1.3.0

Windows x64 is the stable release target. Linux x86_64 CPU packages are offered separately as an **experimental prerelease**, not as Windows support parity. Audio recognition and timing/pause detection stay local.

## Changes since 1.2.0

- Zoom with Ctrl/Cmd + plus/minus; Ctrl/Cmd + 0 resets. This works without an application menu.
- Select TXT, SRT, VTT or JSON before saving. A supported extension typed in the native picker chooses the format. Successful exports remember the folder/name stem for the session; replacement cancellation preserves existing files.
- Choose a saved success/info notification timeout of 5, 10 or 30 seconds, or Never. Timers pause on hover, keyboard focus, app inactivity and while notification preferences are open. Warnings/errors remain until dismissed; identical active errors no longer accumulate.
- Improve narrow windows and initial display sizing, accessible replacement confirmation, empty-export explanations and millisecond subtitle rounding.
- Add experimental Linux CPU packaging with bundled Whisper, Parakeet, FFmpeg and speech-detection resources. Model weights still require an initial download.
- Repair native setup/release tooling and consolidate project documentation.

## Downloads and support

The [stable Windows release](https://github.com/pawn002/talatrace/releases/tag/v1.3.0) provides an unsigned x64 NSIS installer and ZIP, with SHA-256 checksums. Installer and profile identity remain unchanged. Existing downloaded models and preferences are retained by that identity; session History is not a persistent archive.

The [Linux experimental prerelease](https://github.com/pawn002/talatrace/releases/tag/v1.3.0-linux-preview.1) uses the same application version, 1.3.0. **Prefer the deb.** Its executable-specific AppArmor profile and root-owned Chromium sandbox helper retain Chromium sandboxing and Ubuntu's system restriction. AppImage launch remains blocked by Ubuntu's namespace policy on the tested desktop; it is provided for investigation, not as the recommended installation route. Do not disable the sandbox or system-wide restrictions.

Read the [Linux support status](../linux.md#experimental-support-status) and [#24](https://github.com/pawn002/talatrace/issues/24) before installing. Candidate 5 desktop testing covered Ubuntu 26.04.1/XFCE/X11/PipeWire at 150% scale; the build/CI baseline is Ubuntu 24.04. Other distributions, Wayland, ARM64, Linux GPU acceleration, real disconnected desktop use, Orca announcements and the full clean-install/upgrade/remove/data-retention matrix remain unvalidated. No further personal Linux test cycle is required for this experimental release.

## Validation boundaries

Release checks use unit tests, built-app workflow fixtures and actual packaged recognition with HTTP(S) blocked for both engines. Automated fixtures do not establish physical microphone permissions, native GTK portal behavior or a fully disconnected desktop. The Windows zoom preview was also confirmed by the maintainer.

Persistent notification stacks can still clip at their lower edge. Theme tooltips may linger after AT-SPI activation until pointer movement. Very narrow/high-zoom overflow remains a known fixture. Timing/pause metadata is approximate context, not inferred thinking time. These checks do not establish complete accessibility conformance. macOS is not a validated release target; signing is not configured.

The 1.2.0 in-place Windows upgrade was tested; fresh NSIS installation, uninstall and rollback remain separate untested lifecycle cases. Per-release package checks and checksums are recorded in the GitHub release notes.
