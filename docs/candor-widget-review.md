# Candor widget construction review

Reviewed 24 October 2026 against the published [Candor Storybook](https://main--69c25e2492ad056c24329876.chromatic.com) and the released 6.0.0 story and construction files, with follow-ups below. Package versions are pinned to 6.0.0; the card, disclosure, accordion-item, tooltip and toast component entry points are imported, with Lit 3.3.2 as a direct peer dependency. Existing Angular behaviour and native controls remain where the table below records an equivalent construction.

## Inventory and decisions

Source paths below are relative to [Candor's released component sources](https://github.com/pawn002/candor/tree/v6.0.0/src/web-components/components). For each row, reviewed the `.stories.ts` file and corresponding `.ts` construction, including the documentation embedded in the story metadata.
